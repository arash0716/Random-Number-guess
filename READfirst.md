# Random Number Guessing Game

A simple number guessing game written in C.

## Features

- Random number between 1 and 50
- Unlimited guesses
- Shows whether the guess is too high or too low
- Counts attempts  (Try to guess the number within one attempt)
   >if counts are lower than 5 : GOOD
   >if counts are higher than 5 : NOOB

## Compile

```bash
gcc numberguess.c -o game
```

## Run

```bash
./game
```
